## Note

The Vungle Bidding adapter requires setup before beginning. Please contact us at <vxssp@liftoff.io>.

## Bid Params

{: .table .table-bordered .table-striped }
| Name                     | Scope    | Description                                                          | Example       | Type     |
|--------------------------|----------|----------------------------------------------------------------------|---------------|----------|
| `app_store_id`           | required | Vungle App ID of the publisher app, as shown in the Vungle dashboard | `'5123400'`   | `string` |
| `placement_reference_id` | required | Placement Reference ID of the Vungle placement                       | `'912340000'` | `string` |

## Bidding Token

The adapter does not accept the Vungle SDK bidding token as a bid param. Pass the token generated by the Vungle SDK in `user.buyeruid`, or per bidder in `user.ext.prebid.buyeruids.vungle`. Requests without a token do not receive bids.

```json
{
  "user": {
    "ext": {
      "prebid": {
        "buyeruids": {
          "vungle": "<Vungle SDK bidding token>"
        }
      }
    }
  }
}
```

## Rendering

The returned `adm` is a Vungle SDK envelope, not VAST. Render the winning bid with the Vungle SDK.
